# Customer Loyalty Prediction using Machine Learning
# Project Overview
This project predicts customer loyalty tiers using customer demographic and acquisition data using Logistic Regression.

The goal is to classify customers into different loyalty categories based on their characteristics and acquisition information.

This demonstrates why accuracy alone is not sufficient for evaluating classification models.
